## 🇮🇷 فارسی

### 🎯 معرفی

**کارت معرفی تعاملی** — کاربر اطلاعاتش رو وارد می‌کنه و بلافاصله یه کارت شخصی‌سازی‌شده با اطلاعاتش ساخته می‌شه.

این پروژه اولین قدم من توی مسیر یادگیری **جاوااسکریپت** هست و توش با مفاهیم پایه‌ای مثل **مدیریت state، اعتبارسنجی فرم، و دستکاری DOM** آشنا شدم.

### ✨ ویژگی‌ها

- 🎨 **طراحی مدرن و تمیز** — رابط کاربری ساده و حرفه‌ای
- 📱 **کاملاً ریسپانسیو** — روی موبایل، تبلت و دسکتاپ
- ⚙️ **اعتبارسنجی کامل فرم** — چک کردن خالی بودن فیلدها و محدوده‌ی سن
- 🎯 **پیام خطای پویا** — برای هر نوع مشکل، پیام مناسب
- 👤 **ساخت خودکار آواتار** — حرف اول نام کاربر
- 🏷️ **تشخیص خودکار وضعیت سنی** — کودک، نوجوان، یا بزرگسال
- ✨ **واترمارک تعاملی** — اطلاعات سازنده با انیمیشن
- 🌐 **پشتیبانی از RTL** — مناسب برای زبان‌های راست‌به‌چپ

## 🇬🇧 English

### 🎯 About

**Interactive Profile Card** — The user enters their information and instantly gets a personalized card with their data.

This is my first step into learning **JavaScript**, where I got familiar with fundamental concepts like **state management, form validation, and DOM manipulation.**

### ✨ Features

- 🎨 **Modern and clean design** — Simple and professional UI
- 📱 **Fully responsive** — On mobile, tablet, and desktop
- ⚙️ **Full form validation** — Checks for empty fields and age range
- 🎯 **Dynamic error messages** — Appropriate message for each problem
- 👤 **Auto-generated avatar** — First letter of the name
- 🏷️ **Auto age category** — Child, teenager, or adult
- ✨ **Interactive watermark** — Creator info with animation
- 🌐 **RTL support** — For right-to-left languages
